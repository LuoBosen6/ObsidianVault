# **面向对象**
## **什么是面向对象**
**面向对象**（Object-Oriented Programming——OOP）：在面向对象的世界中，一切皆为对象。面向对象的程序是由**对象**组成，每个对象包含**对用户公开的特定功能**和**隐藏的实现部分**（私有属性与内部逻辑——封装）
**面向对象本质**：以**类**的方式组织代码，以**对象**的组织（封装）数据。

|  类  |       对象        |
| :-: | :-------------: |
| 水果  | 苹果、香蕉、芒果、.....  |
| 汽车  | 大众、奥迪、保时捷、..... |
在 Java 中，我们可以定义一个类，然后进一步创建许多这个类的实例对象。像这种编程方式，我们称之为**面向对象编程**

<hr>

## **面向过程和面向对象的区别**
1. 面向过程（C语言）：把数据给函数，函数吐出结果。
		 你把脏衣服给洗衣店的员工，员工把洗好的衣服给你。
2. 面向对象（Java）：对象内含有数据，我对对象说，函数自己计算并返回。
		 你有一个智能洗衣机（里面有脏衣服），你直接按下按下启动按钮，你从洗衣机中拿出洗好的衣服。

| 面向过程                    | 面向对象                 |
| ----------------------- | -------------------- |
| 编写对数据执行操作的“过程”或“方法”（函数） | 创建包含数据和方法（对数据的操作）的对象 |
Java的面向对象特性（封装、继承、多态、抽象）是实现==DRY==[^1]原则最核心、最强大的工具集。
	**DRY**是目标原则，面向对象是实现这个目标的主要方法论。
面向对象是解决问题的一种思想，主要依赖对象之间的交互完成一件事情。

# **类和对象**

**类（class）**
类是构造函数的**模板或蓝图**，我们用它来描述一个实体（对象）所具有的**属性**及**功能**。其中属性成为成员属性或成员变量，功能称为成员方法。
**实例（Instance）/对象（Object）** 
实例（对象）是**类的一个具体实例**。它根据类的蓝图在内存中创建，拥有具体的属性值，并可以执行类中定义的行为。**对象占内存空间**。
```Java
/*
对象：手机
属性：品牌、颜色、内存、尺寸.....
功能：看视频、听音乐、打游戏.....
*/
class MobilePhone{
//成员属性
    String brand;//品牌
    String colour;//颜色
    double internalMemory;//内存
    double size;//尺寸
//成员方法
    public void watchVideo(){
        //看视频
    }

    public void listenMusic(){
        //听音乐
    }

    public void playGame(){
        //打游戏
    }
}
```
规范要求：
1. 类名采用==大驼峰定义==[^2]。
2. 成员前统一为 public。
3. public 修饰的类必须与文件名相同。
4. 一般一个文件当中只定义一个类。

**类的实例化**
定义一个类相当于在计算机中定义了一种新类型，与 int、 double 相似，只不过 int 和 double 是由 Java 语言自带的内置类型，类是用户自己自定义的一个新类型，通过这些类来定义**实例（对象）**，由类 **构造（construct）** 对象的过程成为 **实例化（instantiation）** 。
在 Java 中通过 **new 关键字**可以创建一个对象的实例，通过 . 来访问对象中的属性和方法。通过一个类可以实例化多个对象。

**this关键词**
this 关键字用于表示当前对象的引用。可以用于访问和操作当前对象的属性和方法在方法内部，可以使用 this 关键字来显式地引用当前对象。
this 修饰的变量指代成员变量
```Java
class Person {
    private String name;
    
    public Person(String name) {
	    //this.name指的是当前对象的成员变量 Private String name，右侧 name 指的是构造方法中的参数
	    //因此我们可以用 this 来区分成员变量和参数（避免命名冲突）
        this.name = name;
    }

    public void SayHello() {
        System.out.println("Hello, my name is " + this.name); // 使用this关键字访问当前对象的name属性
    }
}
```
[[构造函数（Constructor）]]和 SayHello 方法中都使用了 this 关键字访问当前对象的属性 name 。
这样做可以明确地指明要操作哪个对象的属性或方法。
**this的用法**
- 引用当前对象的**实例变量**
```Java
class MobilePhone{
    String brand;//品牌
    String color;//颜色

    public MobilePhone(String brand, String colour) {
        this.brand = brand;
        this.colour = color;
    }
}
```
上述代码中，this.brand 和 this.color 分别引用了当前对象的 brand 和 color 实例变量;
- 调用当前对象的**构造函数**
```Java
class MobilePhone{
    String brand;//品牌
    String color;//颜色

    public MobilePhone() {
        this("华为", "黑色")
    }

    public MobilePhone(String brand, String color) {
        this.brand = brand;
        this.color = color;
    }
}
```
上述代码中，this("华为", "黑色") 调用了当前代码中的另一个构造函数;
- 引用当前对象的方法
```Java
class MobilePhone{
    String brand;//品牌
    String color;//颜色

    public String getBrand() {
        return brand;
    }

    public void setBrand(String brand) {
        this.brand = brand;
    }

    public String getColor() {
        return color;
    }

    public void setColour(String color) {
        this.colour = color;
    }
}
```
上述代码中，this.brand 和 this.color 分别引用了当前对象的 brand 和 color 实例变量，并通过 return 返回了 brand 和 color 的实例变量。

**方法的重载**
方法重载（Overloading）是指在**同一个类**中，允许存在**多个同名方法**，只要它们的**参数列表不同**即可。

假如你现在有一个类，类的成员方法是关于两个整数之间的相加。
```Java
class Adder{	
	int sun (int a, int b){
		return a+b;
	}
}
```
```Java
public class void main(String[] args){
	Adder p = new Adder();
	System.out.println(p.sum(10, 20));
}
```
如果有个人不知道是这是整数计算，这个人输入了小数时，程序就会出错，因为程序只能用于计算整数。为了让我们的程序能支持小数进行计算，我们可以将这个方法进行重载。

一个类中可以包含多个同名的方法，但是需要的形式参数（形参）不一样，方法的返回类型，可以相同，也可以不同，但是仅返回类型不同，是不允许的。
```Java
class Adder {
	int sum (int a, int b){
		return a+b;
	}
	//为了支持小鼠加法，我们可以进行一次重载
	double sum(double a, double b){
		return a+b;
		}
}
```
```Java
public class void main(String[] args){
	Adder p = new Adder();
	//当方法出现多个重载的情况，在调用时会自动进行匹配，选择合适的方式进行调用。
	System.out.println(p.sum(1.5, 2.4));
}
```

总结：
1. 必须满足：

| 条件            | 说明                                                  |
| ------------- | --------------------------------------------------- |
| **1. 方法名相同**  | 必须完全相同                                              |
| **2. 参数列表不同** | 满足以下任一情况：  <br>• 参数个数不同  <br>• 参数类型不同  <br>• 参数顺序不同 |
| **3. 在同一个类中** | 包括本类及继承关系中的类                                        |
2. 不构成重载的情况：

|情况|原因|
|---|---|
|只有返回值类型不同|编译器无法区分调用哪个方法|
|只有修饰符不同（如 `public` vs `private`）|不影响方法签名|
|只有异常声明不同|不影响方法签名|
|只有参数名不同|`add(int a)` 和 `add(int b)` 签名相同|

**构造方法(Constructor)**
构造方法的定义：构造函数是一种特殊的**方法**，用于**创建并初始化对象**。当使用 `new` 关键字实例化类时，构造函数会被自动调用，完成对象状态的初始设置。

我们 **创建对象（类的实例化）** 的时候，直接使用 **new** 关键字就直接搞定了，但是，当对象创建（类实例化）后，各种值都是默认值（NULL），为了在对象创建的时候给它相应的属性，我们可以用 **构造方法（构造器）** 来完成。

我们可以用 C语言 中的函数去理解 Java 中的构造方法，构造方法也叫构造函数。

我们有一个人类的属性，包括姓名、年龄、性别。
```Java
//这个类里面没有任何的方法
class Person {
    String name;
    int age;
    String sex;  
}
```
我们给对象指定名称、年龄、性别
```Java
public class Text {
    public static void main(String[] args){
        Person p = new Person();
        p.name = "小王";
        p.age = 12;
        p.sex = "男";
  
        System.out.println("姓名：" + p.name + "，今年 " + p.age + "，性别：" + p.sex);
    }
}
```
我们把类反编译一下，你会发现多出一行方法，这其实是**默认构造方法**
```Java
public class Person {
    String name;
    int age;
    String sex;

    public Person() {    //反编译中，多出来了这样一个方法，这其实就是默认构造方法
    }
}
```

为什么会出现这个默认构造方法？是因为类中**未显式定义任何构造函数**， **编译器（javac）** 会自动生成一个无参构造函数，也就是默认构造方法。

这次我们手动声明方法。
```Java
public class Person {
    String name;
    int age;
    String sex;

	//这是无参构造函数
    Person(){    //构造方法不需要指定返回值，并且方法名称与类名相同
        name = "小明";   //构造方法会在对象创建时执行，我们可以将各种需要初始化的操作都在这里进行处理
        age = 18;
        sex = "男";
    }
}
```
构造方法会在 new 的时候自动执行
```Java
public static void main(String[] args) {
    Person p = new Person();   //这里的new Person()其实就是在调用无参构造方法
    System.out.println(p.name);
}
```

若手动定义了**任何**构造方法，编译器（javac）**不再提供**默认无参构造

在知道了无参构造方法后，我们来给构造方法设定参数
构造方法可以**调用**另一个构造方法（使用`this(...)`），且必须是第一句
```Java
public class Person {
    String name;
    int age;
    String sex;

    Person(String name, int age, String sex){   //跟普通方法是一样的
        this.name = name;
        this.age = age;
        this.sex = sex;
    }
}
```
当我们主动构造出一个构造方法后，会覆盖掉那个无参构方法，当然我们也可以手动重载一个无参构造方法
```Java
public static void main(String[] args) {
    Person p = new Person("小明", 18, "男");   //调用自己定义的带三个参数的构造方法
    System.out.println(p.name);
}
```

总结一下：
构造方法的语法：
- 方法名必须与**类名完全相同**  
- 没有返回值类型（连`void`也不能写）
- 可以有访问修饰符（`public`、`protected`、`private`、默认）
- 可以重载（参数列表不同），但是不能被继承或重写
