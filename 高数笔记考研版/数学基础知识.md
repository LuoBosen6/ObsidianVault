# 一、映射与函数
## 映射
映射（Mapping）指两个集合元素之间的“唯一对应”规则，也就是函数（Function）的广义说法。
设 X、Y 为两个非空集合，若存在一个法则 f ，使 X 中每个元素 x ，按法则 f ，在 Y 中有唯一确定的元素 y 与之对应，那么称 f 为从 X 到 Y 的==映射==，记作： f : X → Y

其中 y 成为元素 x (在映射 f 下)的像，记作 f(x)，即 y=f(x)

补充：
映射三要素：
1. 集合 X ，即定义域 $D_{f}$=X
2. 在法则 f 下，对每个 x ∈ X，都有唯一确定的 y=f(x) 与之对应
3. 集合 Y，$R_f$ ⊂ Y

∀x ∈ X，元素 x 的像 y 是唯一的，但对于每个 y ∈ $R_f$，y 的原像不一定唯一
eg.  {1, 2, -2} →平方→{1, 4}

满射：$R_{f}$=Y   例如： Y = $x^3$
单射：$x_1$ ≠ $x_2$ ，f($x_1$) ≠ f($x_{2}$)  例如：Y = x
既单射又满射 → ==双射==  例如：Y = x
既不单射又不满射  例如：Y = $x^2$
