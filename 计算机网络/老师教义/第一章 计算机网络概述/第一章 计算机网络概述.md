# 计算机网络的基本概念

**定义**：

一般认为**计算机网络**就是利用**通信线路**和**通信设备**将地理上分散的、具有独立功能的多个计算机系统按不同的形式**连接**起来，以功能完善的网络**软件**及**通信协议**实现**资源共享**和**信息传递**的系统。

😸用一条通信线路将两台计算机直接连接起来就可以构成一个最简单的网络。

**分类**：

1. 按网络覆盖范围分类

- 广域网（Wide Area Network，WAN）        几十千米到几千千米，覆盖一个国家或地区，是互联网的核心部分，提供远距离高速连接服务。

- 城域网（Metropolitan Area Network，MAN）5\~50km，覆盖整个城市，城市骨干网，连接企业、校园和机构的局域网。

- 局域网（Local Area Network，LAN）连接范围有限，一个实验室、一栋楼、一个校园。又可分为有线局域网和无线局域网（Wireless Local Area Network，WLAN）

- 个人区域网（Personal Area Network，PAN）不同于以上网络。如鼠标、键盘、打印机、耳机等，通过有线或无线的方式连接到普通计算机。

![image\.png](image.webp)

2. 按网络的使用者分类

- 公用网：按照规定缴纳费用人人都可以使用的网络

- 专用网：满足特殊业务而建造的网络，不对外开放。军用、铁路、电力等

# 2 互联网与互联网络

## 网络

网络由若干**节点**和连接这些节点的**链路**组成。

- 节点：计算机、手机、路由器、交换机等

- 链路：网线、无线

## 互联网络

- 互联网络是“网络的网络”，是由路由器将多个网络连接起来构成的。

- 许多计算机连在一起构成网络，多个网络连在一起构成互联网络。

![image\.png](image%201.webp)

- 直接连接计算机的网络叫**物理网络**，互联网络是由物理网络结合构成的**逻辑网络**

## 互联网

**互联网**是世界上最大的“互联网络”

# 3 电路交换与分组交换（重点）

![YMDzDqSW\.png](YMDzDqSW.webp)

## 电路交换

- “电话网”

- 在通信之前，通信双方要建立一条专用的物理通路，通信结束后释放这条通路。

![GLtx9j2H\.png](GLtx9j2H.webp)

- 通信过程：“建立连接”\-\>“通话”\-\>“释放连接”

    - 建立连接：分配信道资源，建立专用数据通路

    - 通话：一直占用信道通路交换数据

    - 释放连接：归还数据通路的使用权   

## 分组交换

- 采用存储转发技术，发送数据时，无需建立专用的物理通路。先将要发送的“报文”分割成较小的数据段，再将控制信息加在每个数据段的前端构成“分组”。

- 这些“分组”会发给“分组交换机”，它根据“分组”“首部”的目的地信息进行转发。

![Cd2DmaRr\.png](Cd2DmaRr.webp)

- 典型的分组交换机：路由器和二层交换机。

- 分组转发的过程需要时间处理，因此，它有一个输入缓存，用于输入分组的排队。当大量分组需要某一节点转发时，可能出现分组丢失的情况（缓存满，仍有分组转发过来），通常称为网络发生拥塞。

![hKFMuNu3\.png](hKFMuNu3.webp)

## 报文交换

- 与分组交换类似，只是不对报文进行分组。

## 1\. 速率
**比特**（bit）是计算机中*数据量*的单位，“binary digit  二进制数字”， 一个比特就是二进制数字中的一个1或0。  
计算机中的数据量往往用**字节**作为度量的单位。1个字节（Byte，B）代表8个比特。  

| 数据量单位    | 换算关系                     |
| -------- | ------------------------ |
| 比特 (b)   | 基本单位                     |
| 字节 (B)   | 1B = 8b                  |
| 千字节 (KB) | 1KB = $2^{10}$B          |
| 兆字节 (MB) | 1MB = K · KB = $2^{20}$B |
| 吉字节 (GB) | 1GB = K · MB = $2^{30}$B |
| 太字节 (TB) | 1MB = K · GB = $2^{40}$B |
速率就是数据的传送速率，它也称为**数据率**或**比特率**。
速率的单位是**bit/s**（比特每秒），也写为**bps**（bit per second ）。

| 速率的单位               | 换算关系                            |
| ------------------- | ------------------------------- |
| 比特/秒 (b/s 或 bps)    | 基本单位                            |
|                     |                                 |
| 千比特/秒 (kb/s 或 kbps) | 1kb/s = $10^{3}$b/s             |
| 兆比特/秒 (Mb/s 或 Mbps) | 1Mb/s = k · kb/s = $10^{6}$b/s  |
| 吉比特/秒 (Gb/s 或 Gbps) | 1Gb/s = k · Mb/s = $10^{9}$b/s  |
| 太比特/秒 (Tb/s 或 Tbps) | 1Tb/s = k · Gb/s = $10^{12}$b/s |

MB/s 与 Mb/s 只是数值上差了 8 倍

🤔计算机中的存储数据中，1KB、1 MB或1 GB并非表示 $10^{3}$、$10^{6}$或$10^{9}$个字节，而是表示 $2^{10}$、$2^{20}$或$2^{30}$个字节 （计算机组成原理） 。

😩硬盘 U盘存储设备厂家又用 1000 标注，这也是为什么买来的硬盘在电脑里显示的容量“缩水”的原因。

## 2\. 带宽

（1）带宽本来是指某个信号具有的频带宽度。

电话信号的标准带宽是3\.1 kHz （从300 Hz到3\.4 kHz，即话音的主要成分的频率范围）

（2）**在计算机网络中**，带宽用来表示网络某通道传送数据的能力。网络带宽表示在单位时间内从网络中的某一点到另一点所能通过的“**最高数据率**”。   

🤔“频带宽度”越宽， 传输数据的“最高数据率”也越高。  

## 3\. 吞吐量

在单位时间内通过某个网络（或信道、接口）的数据量  

吞吐量经常用于对现实世界中的网络的测量，以便人们了解到底有多少数据量能够通过 网络。😆

## 4\. 时延

**时延**（Delay或Latency）是指数据从网络的一端传送到另一端所需要的时间。

时延有时也称为**延迟**或**迟延**。  

总时延 = 发送时延 \+ 传播时延 \+ 处理时延 \+ 排队时延  

（1）发送时延  

- 发送时延是主机或路由器将整个分组的**所有比特发送到通信线路上**所需要的时间 ， 也叫作**传输时延** 。 

![KNOU2GTD\.png](KNOU2GTD.webp)

（2）传播时延

- 传播时延是电磁波在信道中传播一定距离所花费的时间。

![uADgrZcB\.png](uADgrZcB.webp)

电磁波在**自由空间**中的传播速率是光速        3\.0 × $10^{5}$ km/s  

在**铜线电缆**中的传播速率约为          2\.3 × $10^{{5}}$km/s

在**光纤**中的传播速率约为         2\.0 × $10^{{5}}$ km/s

---

（3）处理时延  

主机或路由器在收到分组时要花费一定的时间进行处理。（分析分组的首部、从分组中提取数据部分、进行差错检验）

（4）排队时延  

分组进入路由器后要先在输入队列中排队等待处理。

![fJr0DSOp\.png](fJr0DSOp.webp)

## 5\. 丢包率

丢包率即分组丢失率，是指在一定的时间范围内，分组在传输过程中丢失的分组数量与总 的分组数量的比率。

在计算机网络中，分组丢失主要有两种情况。

一种情况是分组在传输过程出现了比特级差错，被结点丢弃。

一种情况就是当分组到达一台队列已满的分组交换机时，由于没有空间来存储这些分组，分组交换机就会将到达的分组或已经排队的分组丢弃。 

🤔丢包率较高时，用户感觉到的往往是网络时延变大，“网速” 变慢，而不是信息的丢失。     

## 6\. 利用率

利用率有信道利用率和网络利用率两种。  

- 信道利用率指某信道有百分之几的时间是被利用的（有数据通过）。完全空闲的信道的利用率是零。  

- 网络利用率则是全网络的信道利用率的 加权平均值。  

🤔信道利用率并非越高越好

# 5  计算机网络体系结构

## 1\. 网络协议

为进行网络中的数据交换而建立的规则、标准或约定即称为**网络协议**（Network Protocol）

网络协议三要素

（1）语法，即数据与控制信息的结构或格式。例如，地址字段多长以及它在整个分组中的什么位置。 

（2）语义，即各个控制信息的具体含义，包括需要发出何种控制信息、完成何种动作及做出何种响应。 

（3）同步（或时序），即事件实现的顺序和时间的详细说明，包括数据应该在何时发送出去，以及数据应该以什么速率发送。  

## 2\. 分层体系结构（重点）

- 将网络分成多层结构，每层通过各种协议完成相应工作，最终实现整体的网络功能。

- 按层次来设计有如下好处：

（1）各层之间是独立的。 某一层并不需要知道它的下一层是如何实现的，而仅仅需要知 道该层通过层间的接口（即界面）所提供的服务。  

（2）灵活性好。当任何一层发生变化时（如由于技术的变化），只要层间接口关系保持不变，则该层以上或以下各层均不受影响。  

（3）结构上可分割开。各层都可以采用最合适的技术来实现。  

（4）易于实现和维护。

（5）有利于功能复用。下层可以为多个不同的上层提供服务。  

（6）能促进标准化工作。

（1）应用层

应用层（Application Layer）的任务是通过应用进程间的交互来完成特定的网络应用。应用层协议定义的是应用进程间通信和交互的规则。这里的进 程指正在运行的程序。  

（2）运输层

运输层（Transport Layer，或传输层）的任务就是向两台主机中进程之间的通信提供通用的数据传输服务。 

（3）网络层

网络层（Network Layer）负责为分组交换网上的不同主机提供通信服务。

（4）数据链路层

数据链路层（Data Link Layer）常简称为链路层。从源主机发送到目的主机的分组必须在一段一段的链路上传送。数据链路层的任务就是将分组从链路的一端传送到另一端。  

（5）物理层

物理层（Physical Layer）完成计算机网络中最基础的任务， 即在传输媒体上传送比特流。用什么信号表示 0、1。

## 3\. 实体、协议、服务

- 实体（Entity）：任何可发送或接收信息的硬件或软件进程

- 协议是控制两个对等实体（或多个实体）进行通信的规则的集合

- 要实现本层协议，还需要使用下面一层所提供的服务。 

![ppCgek9Y\.png](ppCgek9Y.webp)

想象你在网上买了个手机，快递员把它送到你楼下的快递驿站：

- 协议：就是快递员和驿站之间约定好的“交接规则”——比如必须扫码入库、轻拿轻放、凭取件码取件。双方都遵守这个规则，才能顺利完成交接。

- 接口：就是驿站那个开放的收货窗口。快递员不需要知道驿站里面货架怎么摆、监控怎么装，他只需要把包裹从这个“窗口”递进去就行。这个窗口是唯一交互的地方。

- 服务：就是驿站提供的最终功能——“代收包裹并通知你”。你不需要关心包裹是怎么从仓库运来的，你只享受“下楼就能拿到手机”这个结果。
