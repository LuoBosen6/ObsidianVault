计算机网络**定义**：计算机网络是利用地理上分散的且具有独立功能的多个计算机系统，通过通信线路和设备在相应软件的支持下实现的数据通信和资源共享的系统

## 计算机网络性能指标
**比特** 是计算机*数据量*的基本单位，一个比特就是*二进制数字中的一个 1 或 0* 

| 数据量单位    | 换算关系                     |
| -------- | ------------------------ |
| 比特 (b)   | 基本单位                     |
| 字节 (B)   | 1B = 8b                  |
| 千字节 (KB) | 1KB = $2^{10}$B          |
| 兆字节 (MB) | 1MB = K · KB = $2^{20}$B |
| 吉字节 (GB) | 1GB = K · MB = $2^{30}$B |
| 太字节 (TB) | 1MB = K · GB = $2^{40}$B |

> [!NOTE] 补充
> 数据量单位中*K、M、G、T*的数值分别为*$2^{10}$、$2^{20}$、$2^{30}$、$2^{40}$*。
---

**速率** 是指*数据的传送速率*（即*每秒可以传送多少个比特*），也成为“*数据传输速率*”、“*数据率*”或“*比特率*”

| 速率的单位               | 换算关系                            |
| ------------------- | ------------------------------- |
| 比特/秒 (b/s 或 bps)    | 基本单位                            |
|                     |                                 |
| 千比特/秒 (kb/s 或 kbps) | 1kb/s = $10^{3}$b/s             |
| 兆比特/秒 (Mb/s 或 Mbps) | 1Mb/s = k · kb/s = $10^{6}$b/s  |
| 吉比特/秒 (Gb/s 或 Gbps) | 1Gb/s = k · Mb/s = $10^{9}$b/s  |
| 太比特/秒 (Tb/s 或 Tbps) | 1Tb/s = k · Gb/s = $10^{12}$b/s |

> [!NOTE] 补充
> 速率单位中*k、M、G、T*的数值分别为*$10^{3}$、$10^{6}$、$10^{9}$、$10^{12}$*。
---

**带宽** 原指*某个信号就有的频带宽度(某信道允许通过信号频率范围）*，单位为*赫兹* (Hz)，简称“赫”
	常见单位有千赫(kHz)、兆赫(MHz)、吉赫(GHz)
**带宽**在计算机网络中用来表示*某信道传送数据的能力*，也就是*单位时间内网络中某信道所能通过的“最高数据率”*，在本集中“宽带”主要表这个意思。这个意思的**带宽单位**为“数据率的单位 bit/s”,也就是*比特每秒*

> [!NOTE] 补充
> 第二章 物理层
> 奈氏准则（奈奎斯特定理）：理想低通信道的最高码元传输速率= **2W（Baud）**
> 	其中 W 为信道带宽（Hz），Baud（波特）是码元传输速率的单位。
> 香农公式（香农定理）：频率带宽受限且有高斯白噪声干扰的信道的*极限信息传输速率*=$W \cdot \log _ { 2 } ( \mathbf { 1 } + S / N )$
> 	其中 W 为信道带宽（Hz）
> 根据香农公式可知，带宽的上述两种含义有密切关系：*信道的“频率带宽”越宽*，其所**传输数据的能力越强**，也就是“*传输数据所能达到的”最高速率“越高*”
---

**时延**（延迟或迟延）指数据从网络的一段传送到另一端所需时间
	总时延 = 发送时延 + 传播时延 + 处理时延 + 排队时延
	![[计算机网络-1789448809166.webp]]
1. **发送时延**：主机或路由器将整个分组的所有比特发送到通信线路上所需时间，也叫做*传输时延*
	$发送时延=\frac { 数据帧长度（bit） } { 发送速率（bit/s }$
2. **传播时延**：电磁波在信道中传播一点距离所需时间，
	$传播时延 = \frac{信道长度（m）}{电磁波在信道上的传播速率（m/s）}$
	- 电磁波在自由空间的传播速率为光速，即 3.0 × $10^{5}$ km/s
	- 电磁波在铜线电缆上传播速率为 2.3 × $10^{5}$ km/s
	- 电磁波在光纤中传播速率为 2.0 × $10^{5}$ km/s

> [!NOTE] 注意
> 发送时延发生在机器内部的发射器中，与传输信道长度（或信号传送距离）无关
> 传播时延发生在机器外部的传输信道媒体上，与信号传送速率无关。信号传送距离越远，传播时延越大
3. **处理时延**：主机或路由器在收到分组时要花费一定时间进行处理
4. **排队时延**：分组进入路由器后要先在输入队列中排队等待处理。

**丢包率**（分组丢包）：指在一定时间范围内，分组在传输过程中丢失的分组数量与总的分组数量的比率

> [!NOTE] 注意
> 在计算机网络中，分组丢失主要有两种情况。
  一种情况是分组在传输过程出现了比特级差错，被结点丢弃。
  一种情况就是当分组到达一台队列已满的分组交换机时，由于没有空间来存储这些分组，分组交换机就会将到达的分组或已经排队的分组丢弃。
🤔丢包率较高时，用户感觉到的往往是网络时延变大，“网速” 变慢，而不是信息的丢失。

---
**利用率**：分为信道利用率和网络利用率
*信道利用率*：指信道有百分之几的时间是被利用的（有数据通过）。完全空闲的信道利用率是零
*网络利用率*：指全网络的信道利用率的加权平均数

> [!NOTE] 注意
>利用率并非越高越好
>当某信道利用率增大时，该信道引起的时延会迅速增加，导致分组在网络节点（路由器或者节点交换机）进行处理时需要排队等待，增加了处理时延和排队时延，最终网络引起的时延会不断增大。
>$D = \frac{D_{0}} {1-U}$
>$D_{0}$表示网络空闲时的时延
>D表示网络当前的时延
>U为当前网络利用率

## 计算机网络体系结构
**网络协议**（网络）：进行网络中的数据交换而建立的规则、标准或约定
	网络协议三要素：
		1. 语法：即数据与控制信息的结构或格式
		2. 语义：即各个控制信息具体含义，需要发出何种控制信息，完成何种动作以及做出何种相应
		3. 同步（时序）：即时间实现顺序的详细说明，包括数据应该在何时发送出去，以及数据应该以什么速率发送
**分层体系结构（重点）**
将网络分成多层结构，每层通过各种协议完成相应工作，最终实现整体网络功能
分层的好处：
1. 各层之间是独立的：某一层并不需要知道它的下一层是如何实现的，而仅仅需要知道该层通过层间的接口（即界面）所提供的服务
2. 灵活性好：当任何一层发生变化时（例如由于技术的变化），只需要层间接口关系保持不变，那么在这层以上或以下各层均不受影响
3. 结构上可分割开。各层都可以采用最合适的技术来实现
4. 易于实现和维护
5. 有利于功能复用。下层可以为多个不同的上层提供服务
6. 能促进标准化工作
>[!NOTE] 补充
>计算机网络各层及其协议的集合就是网络的体系结构。计算机网络体系结构就是这个计算机网络及其构件所应完成的功能的精确定义。
>总之，体系结构是抽象的，而实现则是具体的，是真正在运行的计算机硬件和软件
>
>- OSI/RM （简称OSI） —— 开放系统互连基本参考模型
>- 在OSI模型之前，TCP/IP协议簇就已经在运行，并逐步演变成TCP/IP参考模型（实际上的国际标准，很成功）

1. 应用层：通过应用进程间的交互来完成特定网络应用。应用层协议定义的是应用进程间通信和交互的规则。这里进程指主机正在运行的程序
2. 运输层：向两台主机中进程之间的通信提供通用的数据传输服务
	运输层主要使用以下两个协议：
	1. *传输控制协议TCP*：提供面向连接的、可靠的数据传输服务，其数据传输的单位是**报文段**
	2. *用户数据报协议UDP*：提供无连接的尽最大努力的数据传输服务（不保证数据传输可靠性），其数据传输单位是用户数据报
3. 网络层：为分组交换网上的不同主机提供通信服务。在发送数据时，网络层把运输层产生的报文段或用户数据报封装成**分组**或者**包**进行传送。
	在 TCP/IP 体系中，由于网络层是用 IP 协议，因此分组也成为**IP数据报**（简称数据报）
4. 数据链路层（链路层）：从源主机发送给到目的主机的分组必须在一段一段的链路上传送。
