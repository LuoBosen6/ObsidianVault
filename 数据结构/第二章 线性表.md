本章节，你要学会区分线性表的静态存储和动态存储，以及线性表的基本操作：创建、求长度、查找、插入、删除、遍历。

**线性表**是具有相同数据类型的 n （n ≥ 0）个数据元素的有限序列，其中 n 表示表长，当 n = 0 时表示线性表是一个空表。

**顺序表**：采用顺序存储结构的线性表称为顺序表。顺序表指用一组地址连续（物理连续）的存储单元依次存储线性表的数据元素
L = ($a_1$,  $a_2$, ...., $a_i$, ...., $a_n$)
![[线性表定义.jpeg|700x136]]
LOC（$a_i$）= LOC（$a_1$）+（i-1）* L （1 ≤ i ≤ n） 其中，L是元素占用存储单元的长度。
### 顺序表的静态分配
顺序表的静态分配之所以是静态的，是因为定义了 MAXSIZE 的大小，也就是数组的最大值 data[MAXSIZE]，且不可改变。

静态分配的初始化
```C
//顺序表的实现————静态分配
#include<stdio.h>
#define MAXSIZE 10 //定义顺序表的最大长度

typedef struct {
	int data[MAXSIZE];  //用静态的‘数组’存放数据元素
	int length; //顺序表的当前长度
}SqList;  //顺序表的类型定义（静态分配）

//初始化
void InitList(SqList *L){
/*可无视这一步，可以手动清空数组
	for(int i = 0; i < MAXSIZE; i++){
	L->data[i] = 0;  //并非是 0 ，这里是默认初始值，是多少都行，根据题意
	}
直接让数组长度为零就可以了，但是如果只运行这一步，那么你遍历数组后发现是乱码
*/
//这串代码是告诉程序“这个表现在是空的，没有有效元素”，
//L->data 的数组里面依旧有数字（垃圾值，无效值，乱码）
	L->length = 0;
}
//主程序
int main(){
	SqList L;   //声明一个顺序表
	InitList(&L);   //初始化一个顺序表
	return 0;
}
```

### 顺序表的动态分配
顺序表的动态分配核心思想是在**运行**时，根据实际需要**动态申请**内存空间，当空间不够的时候，可以**再分配更大的空间**，并把原有的数据复制过去，然后释放旧空间。

动态分配的初始化
```C
void InitList(SeqList *L){
	L->data = (int*)malloc(INIT_CAPACITY * sizeof(int));
	L->length = 0;
	L->capacity = INIT_CAPACITY;
}
```
**顺序表的动态分配的扩容**
扩容的通用逻辑是：
1. 检查容量：在插入新元素前，判断当前存储空间是否已满。
2. 申请新空间：如果已满，则申请一块更大的新内存空间。常见的扩容策略是将容量扩大为原来的 2 倍。
3. 迁移数据：将旧空间中的所有数据复制到新空间中。
4. 释放旧空间：释放原先的内存空间，避免内存泄漏。
5. 更新指针和容量：让顺序表的指针指向新的内存地址，并更新其容量记录。

| 策略   | 操作方式                    | 优点                | 缺点                                | 适用场景                                    |
| :--- | :---------------------- | :---------------- | :-------------------------------- | :-------------------------------------- |
| 固定增量 | 每次扩容增加固定数量（如 +10, +100） | 节省内存空间，浪费少        | 频繁扩容，每次都要调用 `realloc` 并可能移动数据，效率低 | 对内存极其敏感，且数据量增长缓慢的场景                     |
| 倍数扩容 | 每次扩容翻倍（如 ×2）或 ×1.5      | 效率高，减少了扩容和内存拷贝的次数 | 可能会浪费一定的内存空间（尤其是扩容后未存满时）          | 通用场景（如 C++ `std::vector`，Python `list`） |
1. 固定增量：
	- 做法：每次扩容，增加一个固定的常数大小
	- 代码示例：new_capacity = capacity + INCREMENT_SIZE
```C
#include <stdlib.h>

#define INIT_SIZE 10      // 初始容量
#define INCREMENT 5       // 每次扩容增加的量

typedef struct {
    int *data;            // 指向动态数组的指针
    int length;           // 当前元素个数
    int capacity;          // 当前容量
} SeqList;

// 固定增量扩容
void IncreaseSize(SeqList *L) {
    int newCapacity = L->capacity + INCREMENT;
    int *newData = (int*)malloc(newMaxSize * sizeof(int));
    
    // 复制原数据
    for (int i = 0; i < L->length; i++) {
        newData[i] = L->data[i];
    }
    
    // 释放旧内存
    free(L->data);
    
    // 更新指针和容量
    L->data = newData;
    L->maxSize = newMaxSize;
}
```
2. 倍数增量
	- 做法：每次扩容，容量变为原来的几倍
	- 代码示例：new_capacity = capacity * 2
```C
#include <stdlib.h>

#define INIT_SIZE 10      // 初始容量

typedef struct {
    int *data;            // 指向动态数组的指针
    int length;           // 当前元素个数
    int capacity;          // 当前容量
} SeqList;

// 倍数增量扩容（翻倍）
void IncreaseSize(SeqList *L) {
    int newCapacity = L->capacity * 2;
    int *newData = (int*)malloc(newMaxSize * sizeof(int));
    
    // 复制原数据
    for (int i = 0; i < L->length; i++) {
        newData[i] = L->data[i];
    }
    
    // 释放旧内存
    free(L->data);
    
    // 更新指针和容量
    L->data = newData;
    L->maxSize = newMaxSize;
}
```
动态申请和释放内存空间：
- C：malloc、free函数
	- L->data = (int*) malloc (sizeof(int) * INIT_CAPACITY);
	- malloc函数返回一个指针， 空间需要强制转型为你定义的数据元素类型指针
	- malloc函数的参数，指明要分配多大的连续内存空间
- C++： new、delete关键字

### 顺序表的基本操作
顺序表的静态分配和动态分配的基本操作都一样。

1.插入操作：平均时间复杂度 O(n)
插入操作：必须从后向前，用前面的数据覆盖后面的数据
```C++
bool InsertList(Seqlist &L, int pos, int e){
	//判断线性表是否存在和插入位置是否合法
	if(Lpos < 1 || pos > L.length + 1) return 0;
	//判断当前表是否满了
	//如果L.length = MAXSIZE 的话
	//for循环就会导致数组的溢出
	if(L.length >= MAXSIZE) return 0;
	//把第 pos 个 元素及其之后的元素后移
	for(int i = L.length; i >= pos; i--) {
	L.data[i] = L.data[i-1]; //后面的元素等于前一个元素
	}
	L.data[pos-1] = e;  //在位置 pos 放入 e
	L.length++;  //长度加一
}
```
2. 删除操作：平均时间复杂度 O(n)
删除操作：必须从前向后，用后面的数据覆盖前面的数据
```C++
bool DeleteList(SeqList &L, int pos, int &e){
	//判断插入的位置是否有效
	if(pos < 1 || pos > L.length) return 0;
	e = L.data[pos - 1];  //将删除的元素赋值给 e
	//将第 pos 个后面的元素向前移
	for(int i = L.pos; i < L.length; i--) {
	L.data[i-1] = L.data[i];
	}
	L.length--;
	return 1;
}
```
3. 尾插法：平均时间复杂度 O(1)
尾插操作：将新的数据元素 e 放在当前最有一个数据元素的后面
```C++
bool InserTailList(SeqList &L, int e){
	//判断表是否已满
	if(L.length >= MAXSIZE) return 0;
	//将新的数据元素 e 放在当前最有一个数据元素的后面
	L.data[L.length] = e;
	L.length++;
	return 1;
}
```
4. 按值查找：平均时间复杂度：O(n)
按值查找操作：查找给定关键字值的数据元素，返回它的位序
```C++
int LocateElem(SeqList &L, int e){
	for(int i = 0; i < L.length; i++){
		if(L.data[i] == e) return i+1;
	}
	return 0;
}
```

5. 按位查找：平均时间复杂度 O(1)
按位查找操作：获取表 L 中第 i 个位置的数据元素的值
```C++
int GetElem(SeqList &L, int pos){
	//判断位置是否合法
	if(pos < 1 || pos > L.length) return 0;
	return L.data[pos - 1];
}
```
