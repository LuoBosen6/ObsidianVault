## 单链表
线性表的链式存储又称单链表
```
typedef struct LNode{
	int data;
	struct LNode *next;
}LNode, *LinkList;
```

创建头节点的方式
```C++
//方法一：C++引用
bool InitList1(LinkList &pHead){
    pHead = (LNode*) malloc (sizeof(LNode));
    if(pHead == NULL) return false;
    pHead->next = NULL;
    return true;
}
```
```C
//方法二：C指针

bool InitList2(LNode **L){
    *L = (LNode*) malloc (sizeof(LNode));
    if((*L) == NULL) return false;
    (*L)->next = NULL;
    return true;
}
```
