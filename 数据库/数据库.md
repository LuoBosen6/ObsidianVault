## 数据库系统概述

数据（Data）定义：描述事物的符号记录

数据库（Database，简称 DB）：长期存储在计算机内、有组织的、可共享的大量数据的集合

数据库管理系统（DBMS）位于用户与操作系统之间的一层数据管理软件

组织和存储数据、高效地获取和维护数据；提供数据定义语言（DDL）定义数据库中的数据对象；提供数据操纵语言（DML）实现对数据库的基本操作（查询、插入、删除和修改）

数据库系统（Database System，简称 DBS）= 数据库 ＋ 数据库管理系统+应用程序+数据库管理员（DBA）

## 数据模型

1. 概念模型（信息模型）

   它按照用户观点来对数据和信息建模，用与数据库设计。

2. 逻辑模型和物理模型

   1. 逻辑模型：主要包括网状模型、层次模型、关系模型。按计算机系统的观点对数据建模，用于 DBMS 实现。
   2. 物理模型：藐视数据在系统内部的表示方式和存取方式，在磁盘或磁带上的存储方式和存取方法

概念模型的一种表示方法：实体-联系方法（E-R 图）

1. 实体：客观存在并可相互区别的事务称为实体。具体的人、物，也可以是抽象的概念。例如：“学生”、“课程”、“部门”。
2. 属性：实体所具有的某一特性称为属性。一个实体可以有若干个属性。例如：“学生”实体可以有“学号”、“姓名”、“性别”等属性。
3. 码：唯一标识实体的属性集称为码
4. 联系：实体与实体之间的相互关联。例如：“学生”和“课程”之间存在“选修”的联系。

实体之间的联系有三种：一对一、一对多、多对多
例如：

1. 一对一：系和正系主任的联系
2. 一对多：系和教师的联系
3. 多对多：教师和课程的关系

数据模型组成要素：数据结构、数据操作和数据的完整性约束条件

1. 数据结构：描述数据库的组成对象，以及对象之间的联系
2. 数据操作：查询更新（包括插入、删除、修改）
3. 数据的完整性约束条件：给定的数据模型中数据及其联系所具有的制约

## 关系模型中的主码、外码的概念，并说明主码和外码的作用

1. 主码（键）：主码是关系表中用于唯一地确定一个元组的属性或最小属性组，其作用是使表中的每一行数据彼此不重复且有意义
2. 外码（键）：外码是引用另一个表的主键的表中的一个列，其作用是表示两个或多个实体之间的关联关系

## 关系模型的数据完整性包括哪些内容？分别说明每一种完整性的作用

数据完整性约束主要包括三大类，即实体完整性参照完整性和用户定义的完整性

1. 实体完整性是保证关系数据库中所有的表必须有逐渐，且主键不允许为空
2. 参照完整性用于描述实体之间的关联关系
3. 用户完整性实际上是约束关系中属性的取值范围，即保证数据库中的数据符合现实语义

## 数据库系统包含哪三级模式？分别说明每一级模式的作用

数据库系统包含的三级模式为：内模式、模式和外模式。

1. 外模式（子模式或用户模式）：数据库用户（包括应用程序员和最终用户）使用的局部数据的逻辑结构和特征的描述。
2. 模式（逻辑模式）：数据库中全体数据的逻辑结构和特征的描述，是所有用户的公共数据视图。
3. 内模式（物理模式）：是数据物理结构和存储方式。

## 二级映像

外模式 / 模式 映像定义了数据的局部逻辑结构与全局逻辑结构之间的对应关系（逻辑结构）
	当模式改变时（新增关系、属性、改变属性数据类型等），由数据管理员对各个外模式/模式映像作相应改变，可以使外模式保持不变，保证了数据与程序的**逻辑独立性**

模式 / 内模式 映像定义了数据的全局逻辑结构与存储结构之间的对应关系（存储结构）
	当数据库的存储结构改变时，由数据库管理员对模式/内模式映像作相应改变，可以使模式保持不变，从而应用程序也不必改变，保证了数据与程序的**物理独立性**

# SQL

数据类型：

| 类型       | 说明                                          |
| ---------- | --------------------------------------------- |
| char(n)    | 固定长度字符串，表示 n 个字符的固定长度字符串 |
| varchar(n) | 可变长度字符串，表示最多有 n 个字符的字符串   |
| int        | 整型                                          |
| smallint   | 短整型                                        |

创建表：

```SQL
CREATE TABLE 表名
(
列名1 数据类型 列级完整性约束条件
列明2 数据类型 列级完整性约束条件
....
);
/*
表名：所要定义的基本表的名字
列名：组成该表的各个属性（列）列级完整性
约束条件：涉及相应属性列的完整性约束条件主键，外键，非空，唯一
（1）NOT NULL：表示不允许取空值；
（2）UNIQUE：表示取值唯一；
（3）NOT NULL UNIQUE：表示取值唯一且不为空；
（4）CHECK：限制列中值的取值范围。如：CHECK(Sex = '男' OR Sex = "女"),CHECK(余额 >= 0),CHECK(年龄 >= 18 AND 年龄 <= 60)
```

```SQL
例如：建立“学生表”Student。学号为主码，姓名取值唯一
CREATE TABLE Student
(Sno char(9) PRIMARY KEY,
Sname char(20) UNIQUE,
 Ssex char(2),
 Sage SMALLINT,
 Sdept char(20)
);
创立一个“课程表”Course，课程号为主键，课程名不为空。
CREATE TABLE Course
(Cno int PRIMARY KEY
Cname char(40) NOT NULL,
 Cpno char(4),
 Ccredit SMALLINT
)
```

修改表：

```SQL
ALTER TABLE 表名
ADD 新列名 数据类型 完整性约束
MODIFY 列名 新数据类型 新约束
DROP 列名
ADD 字句用于增加新列、新的列级完整性约束条件和新的表级完整性约束条件
MODIFY 子句用于修改列名和数据类型
DROP 子句用于删除指定列名
```
