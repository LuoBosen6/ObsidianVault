# 第一章 基础知识
汇编语言是直接在硬件上工作的编程语言，本章我们对硬件系统结构的问题进行一部分的探索，为以后的章节打好基础，汇编语言的研究重点是如何利用硬件系统的编程结构和指令集有效灵活地控制系统进行工作

## 机器语言
机器语言是机器指令的集合，机器指令就是一台机器可以正确执行的命令。电子计算机的机器指令是一列二进制数字，计算机将其转变为一列高低电平，以便计算机的电子器件收到驱动，进行运算。

早期的计算机是指可以执行机器指令，进行运算的机器。如今，我们常用的 PC 机中，有一个芯片来完成上面所说的计算机的功能。这个芯片就是我们常说的 CPU （Central Processing Unit，中央处理器），CUP 是一种微处理器。现在，我们提到的计算机是指由 CPU 和其他受 CPU 直接或间接控制的芯片、器件、设备组成的计算机系统。

每种微处理器，由于硬件设计和内部结构的不同，需要不同的电平脉冲来控制。因此，每种微处理器都是自己的机器指令集，也就是机器语言。

早期的程序均使用机器语言，程序员用 0、1 数字编程的程序代码在纸带或卡片上，1打孔，0不打孔，再将程序通过纸带机或卡片机输入计算机，进行计算。

用 8086CPU 完成运算 s = 768 + 12288 - 1280，机器码如下：
101110000000000000000011
000001010000000000110000
001011010000000000000101
假如写错一个0或者1，结果就不正确了  

## 汇编语言的产生
早期的程序员发现使用机器语言非常麻烦，于是汇编语言产生了。

汇编语言的主体是汇编指令，汇编指令和机器指令的差别在于指令的表示方法上。汇编指令是机器指令便于记忆的书写格式，为什么这么说，请看下面的例子。

操作：寄存器 BX 的内容送到 AX 中
机器指令：1000100111011000
汇编指令：mov AX,BX 
（寄存器：CPU中存储数据的器件，一个 CPU 有多个寄存器，AX 是其中的一个寄存器的代号，BX 是另一个寄存器的代号）

此后，程序员用汇编指令编写源程序，编译器把汇编指令编译成机器指令（机器码），计算机接收到进行相关的操作。

## 汇编指令的组成

汇编语言由 3 类指令组成：
1. 汇编指令：机器码的助记符，有对应的机器码
2. 伪指令：没有对应的机器码，由编译器执行，计算机不执行
3. 其他符号：如 +、-、* 、/ 等，由编译器识别，无对应机器码

其中，汇编语言的核心是**汇编指令**，汇编指令决定了汇编语言的特性

## 存储器

CPU 是计算机的核心部件，它控制着整个计算机的运行并进行运算。我们如果想让 CPU 工作，就必须向 CPU 提供指令和数据。指令和数据就存放在存储器中，也就是我们所说的内存。（之后我们会详细将存储器，这里是为了引入指令和数据））

## 指令和数据

指令和数据本质上没有任何区别，都是一组二进制信息。
如：内存中二进制信息：1000100111011000
10001 00111 01100  $\to$  89D8H （数据）
10001 00111 01100  $\to$  mov AX,BX  （程序）

## 存储单元
存储器被划分为若干个存储单元，每个存储单元从 0 开始顺序编号。这些编号可以看作是存储单元在存储器中的地址。

计算机中最小信息单位是 bit，也就是 一个二进制位，8 个 bit 组成一个 Byte，也就是一个字节。微型存储器的每个存储单元可以存储一个Byte，即 8 个二进制位。如果一个存储器有 128 个存储单元，那么它可以存储 128 个Byte，我们说这个存储器的容量是 128 个字节。

| 1KB = 1024B | 1MB = 1024B | 1GB = 1024MB | 1TB = 1024GB |

## CPU 对存储器的读写
CPU 如果想从内存中读数据，首先要指定存储单元的地址。

CPU 如果想进行数据的读写，必须和外部器件进行以下三类信息交换
- 存储单元的地址  （地址信息）
- 期间的选择，读或写的命令  （控制信息）
- 读或写的数据  （数据信息）

CPU 是如何将地址、数据和控制信息传到存储器中呢？计算机中处理、传递的信息都是电信号，而电信号是通过导线传递的，所以我们把 CPU 和其他芯片之间的导向称为**总线**。

总线从物理上来讲，就是一根根导线的集合
总线从逻辑上来讲分为 3 类：
1. 地址总线
2. 控制总线
3. 数据总线
